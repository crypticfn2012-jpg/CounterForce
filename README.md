# CounterForce\n\nLightweight browser tactical FPS built from scratch with HTML, CSS, JavaScript and Three.js.\n\n## Play\nUse any local static HTTP server, for example `python -m http.server 8080`, then open http://localhost:8080.\n\n## Included\n- First-person movement, pointer lock, sprint, crouch and jump\n- ADS-style FOV transition\n- Original low-poly tactical map and procedural weapon models\n- Pistols, SMGs, rifles, shotguns, snipers, LMG and knife\n- Recoil, spread, headshots, armor, health, reloads and hit detection\n- Deathmatch, tactical round mode and practice\n- Buy phase and local loadout selection\n- Bots with Easy/Normal/Hard/Expert-ready behaviour\n- Kill feed, scoreboard, timer, health and ammo HUD\n- Local settings, stats and procedural Web Audio\n- GitHub Pages-ready static deployment\n\n## Controls\nWASD move, mouse look, left click fire, right click ADS, R reload, 1/2/3 weapon slots, C crouch, Shift sprint, Space jump, Tab scoreboard, Esc pause.\n\n## Architecture\nCore, input, player, weapons, AI, map, match, UI, audio, settings, save and performance code are separate modules. Multiplayer is deliberately a later phase; local gameplay is the first stable target.\n\n## Originality\nCounterForce is independently implemented with original procedural geometry, UI and audio. It does not copy Clutcher.io source code, assets, branding, textures, models or sounds.
